# Branding assets

`simeji.png` is the Simeji 23.6.1 app logo from the supplied XAPK. It is a runtime product asset, used at the user's request for the Windows input indicator.

`simeji.ico` contains the same logo at 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixels, with alpha transparency. The IME build embeds it into the DLL's first icon group. Keep both files in sync when replacing the app logo.

The input mode glyphs use the installed Windows Meiryo font; no font files are bundled.
